# GPS 速度计

实时显示当前位置的行进速度，并集成高德地图导航 SDK，支持在导航过程中查看前方红绿灯倒计时。

## 功能

- 实时速度显示（大字号，深色背景）
- km/h 与 MPH 单位一键切换
- 显示 GPS 精度与坐标
- GPS / 网络双定位，按可用信号自动切换
- 🚦 附近红绿灯：无需输入目的地，自动定位当前位置并自动规划一段前方路线进入导航模式，实时显示沿路红绿灯灯态与前方红绿灯数量

## 技术

- Kotlin + Material 3
- 原生 LocationManager 实现速度显示
- 高德导航 SDK（`com.amap.api:navi-3dmap`）实现红绿灯导航
- minSdk 26，targetSdk / compileSdk 35
- 支持 armeabi-v7a、arm64-v8a

## ⚠️ 重要：需要配置高德 Key 与授权

**红绿灯导航功能依赖高德地图开放平台的授权，必须先申请 Key 才能正常使用。**

### 一、申请高德开发者 Key

1. 访问 [高德开放平台](https://lbs.amap.com/)，注册并登录账号。
2. 完成**个人开发者认证**（导航 SDK 需要实名认证）。
3. 进入控制台 → 「应用管理」→「我的应用」→「创建新应用」。
4. 在应用下「添加 Key」：
   - 服务平台选择 **「Android 平台」**
   - **安全码 SHA1**：打开 APP，主界面点 **「⚙ 设置高德 Key」**，界面上会自动显示当前 APK 的 SHA1，把那个 SHA1 复制填写到高德平台即可。
5. 提交后会生成一串 Key（形如 `xxxxx...`），复制它。

### 二、在软件内填入 Key（无需改项目配置）

1. 安装 APK 并打开。
2. 主界面点 **「⚙ 设置高德 Key」**。
3. 把申请到的 Key 粘贴进输入框。
4. 点 **「检测 Key 是否有效」** 可立即验证 Key 是否可用（有效/无效/网络错误）。
5. 点「保存」，回到主界面点 **「🚦 附近红绿灯」** 即可查看当前位置附近的红绿灯。

Key 会保存在手机本地（SharedPreferences），无需重新打包。

> 提示：如果换了签名重新打包（SHA1 变化），或 Key 失效，重新在弹出的界面里换 Key 即可。

### 三、关于导航 SDK 的商务授权

高德的**导航 SDK**（不同于地图/定位 SDK）属于商业授权产品，免费支撑期有限，正式商用需提交商务合作工单。个人测试可在申请 Key 后按官方指引获取试用权限。红绿灯倒计时的**精确读秒**能力也属于需要开通的增值能力；基础的红绿灯图标与灯态会随导航地图显示。

> 若在导航时提示「授权失败 / key 无效 / 需要配置 Key」，请确认：软件内已填 Key、填写的 SHA1 与当前 APK 一致、已完成开发者认证，并联系高德开放平台开通导航授权。
